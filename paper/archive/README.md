# Earlier Track A manuscript

[track-a-legacy.pdf](track-a-legacy.pdf) and [its source](track-a-legacy.tex) preserve
the Track A manuscript from the previous public repository revision, before the
20 September 2026 rewrite.

This is historical material. Its headline carbon and cost advantages are
superseded by the [current paper](../main.pdf). The compared local and cloud
workloads and accounting boundaries differed, task quality was not matched,
and assumptions were described too strongly. See the
[revision report](../../review/REVIEW_REPORT.md).

The older figure files and their generation code remain in `figures/` and
`models/` for inspection and reuse with their original assumptions disclosed.
The archived source uses the older `paper/empirical.tex` and
`paper/references.bib`. It is not the current publication manuscript.
