# Earlier Track A manuscript

[track-a-legacy.pdf](track-a-legacy.pdf) and [its source](track-a-legacy.tex) preserve
the Track A manuscript as it stood in the public repository from 6 to 20 September
2026, titled *Right-Sized AI at the Edge: Quantifying Carbon, Water, Cost, and
Capability in Peer-to-Peer Inference*.

Both current Track A papers descend from it:

- [`../p2p-inference.pdf`](../p2p-inference.pdf) continued the same study as
  research release v0.3.0, with measured statistics, a claims ledger, and a
  citation audit.
- [`../right-sized-edge.pdf`](../right-sized-edge.pdf) is a narrower revision that
  replays the stored measurements. It does not carry forward this draft's headline
  carbon and cost advantages: the compared local and cloud workloads and
  accounting boundaries differed, task quality was not matched, and assumptions
  were described too strongly. See the [revision report](../../review/REVIEW_REPORT.md).

This is historical material. The archived PDF is the record. Its source expects the
figure set, `paper/empirical.tex`, and `paper/references.bib` of Git commit
`fa15395`; those files now carry the v0.3.0 versions, so check out that commit to
rebuild the draft exactly.
