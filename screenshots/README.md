# Demo assets

This folder contains the small, public reference kit for the research README
and a future product demo capture.

## Live surface

- `test-autoyou-cloud-plans.png` is a public browser capture of
  `https://test.autoyou.me/`.
- `test-autoyou-plans-detail.png` and `test-autoyou-plans-dark.png` capture
  the lower plan section and its alternate theme.
- The capture shows the public cloud-plan landing screen. It is not a
  signed-in workspace screenshot.

## Research evidence

- `edge-capability-routing.png` is the capability-routing figure.
- `edge-savings-by-baseline.png` is the baseline sensitivity figure.
- `edge-quality-vs-coverage.png` is the adaptation quality and coverage
  figure.
- `edge-measured-energy.png` is the measured GPU energy figure.

The four evidence images are copies of the generated figures in `figures/`.
The figures remain the source of truth for the paper.

## Live native mobile demo

- `autoyou-mobile-demo-live-native.mp4` is the 45-second uncaptioned master
  from the real AutoYou Android app on a disposable emulator. It shows an
  active connection, a typed request, a live reply, and a return to the
  connection view.
- `autoyou-mobile-demo-live-vertical.mp4` is the 36-second portrait social
  cut with inlaid captions. It is continuous footage with no slide cards,
  zoom pans, crossfades, or screenshot sequence.
- `autoyou-mobile-demo-live-poster.png` is the captioned poster frame.
- `mobile-demo-live-capture.md` documents the safe capture conditions.
- `mobile-demo-live-captions.ass` is the editable caption track.

The reply was exercised against a disposable local AutoYou Lite fixture with
synthetic provider text. It is not a signed-in `test.autoyou.me` workspace
capture.

## Screenshot-based portrait reference

- `autoyou-mobile-demo-vertical.mp4` is a 23-second 1080 x 1920 walkthrough
  built from real AutoYou mobile UI captures. It is preserved as an earlier
  visual treatment reference and is not the primary live demo.
- `autoyou-mobile-demo-vertical-poster.png` is the portrait README poster.
- `mobile-demo-script.md` records the sequence and caption copy.

## Video reference

- `test-autoyou-reference.mp4` is a short browser-state reel made only from
  the public `test.autoyou.me` entry screen.
- `test-autoyou-vertical-reference.mp4` is the portrait version of the live
  public-site reference, with the same signed-out caveat.
- `research-demo-reference.mp4` is a short static reference reel made from
  the public browser states and the generated figures. It is a visual
  reference for a later narrated recording, not a claim that the live product
  was exercised end to end.
- `demo-script.md` is the capture plan for a future interactive recording.
